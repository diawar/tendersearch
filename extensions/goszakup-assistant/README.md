# Тестовая сборка расширения Chrome

Установка: chrome://extensions → Режим разработчика → Загрузить распакованное расширение → выбрать эту папку.

Откройте кабинет https://zakup.gov.kz/cabinet/ и самостоятельно войдите через ЭЦП. Откройте расширение и нажмите «Проверить форму». Результат содержит только названия видимых полей и кнопок, без значений, cookies, токенов или ключей. Передайте его агенту для уточнения поддержки формы.

После проверки сохраните подготовку в карточке интересного лота нашего ПО, скачайте JSON и выберите его в расширении. Файл содержит реквизиты: храните его приватно. Он остаётся только в памяти popup и теряется при закрытии окна. При подтверждённых БИН, объявлении и лоте можно заполнить обычные поля товара/изготовителя/телефона. Расширение ничего не отправляет на сервер приложения, не нажимает кнопки портала, не обрабатывает ЭЦП, не подписывает и не подаёт заявки.

Это сборка для проверки связи и структуры формы. Автоматическое создание черновика, выпадающие списки, сохранение обеспечения, фоновая очередь и восстановление после сетевого обрыва ещё не реализованы. Не используйте её как готовый автоподаватель.


## Чтение статуса (0.2.2)

Поддерживается список с раздельными таблицами заголовков и строк. Таблицы сопоставляются только внутри общего контейнера при однозначной структуре; неоднозначная разметка не подтверждает статус.

В «Моих заявках» найдите нужное объявление. Откройте расширение, загрузите файл подготовки и нажмите «Проверить статус». Сверяются БИН в шапке, номер объявления и лота в одной строке, статус заявки и ссылка на её карточку. При неоднозначности, фильтрах, пагинации или незнакомой разметке выводится unknown — это не отсутствие заявки. «Проект» распознаётся как draft, точные статусы «Подана/Подано/Заявка подана» — submitted. Кнопка «Скачать отчёт» сохраняет JSON без токенов и реквизитов. В приложении на странице подготовки выберите отчёт и нажмите «Обновить статус». Автоматическая отправка отчёта и постоянная фоновая синхронизация не реализованы. Сначала проверьте эту сборку на реальной странице: селекторы и вид ссылки могут отличаться, тогда потребуется адаптация. Не меняйте отчёт вручную.
