# Основа приложения и результаты проверки

Этап 2 завершён 27 октября 2026 года. Приложение запущено локально через Docker Compose по адресу http://localhost:8000. Доступно только с этого компьютера.

## Реализовано

- Django 5.2: вход, выход методом POST, защищённая стартовая страница и административная панель.
- Закрытая регистрация: пользователей создаёт администратор. Обычный пользователь не получает доступ к административной панели.
- Личные счётчики поисков, избранного и уведомлений фильтруются по текущему пользователю.
- Модели заказчиков, объявлений, лотов, документов и их версий, поисковых профилей и запусков, совпадений, избранного и уведомлений. Создана начальная миграция с ограничениями уникальности.
- PostgreSQL 17, Redis 7 и Celery с одним процессом worker; задача проверки работоспособности очереди.
- Общий ограничитель частоты обращений к источнику через Redis. Для будущих веб-запросов использовать source_client из tender_search.core.source.
- Автоматическая инициализация базы и первого администратора. Повторная инициализация сохраняет существующий пароль.
- Генерация случайных секретов в .env и данных первого входа в data/first-login.txt. Оба файла исключены из Git и контекста Docker.
- Стили обслуживаются WhiteNoise; приложение в контейнере запускается через Gunicorn от непривилегированного пользователя.
- Именованные тома базы, документов и очереди. У PostgreSQL и Redis нет опубликованных портов; веб-порт привязан к 127.0.0.1.
