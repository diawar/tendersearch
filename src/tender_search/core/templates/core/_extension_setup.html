Расширение Chrome

Помощник подготовки заявки: создание и заполнение черновика ЗЦП, чтение статуса в открытом кабинете Госзакупа.

Скачать расширение ZIP
  1. Скачайте архив и распакуйте его в постоянную папку на своём компьютере.
  2. В обычном Google Chrome откройте chrome://extensions.
  3. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку goszakup-assistant, в которой лежит manifest.json.
  4. Войдите в кабинет Госзакупа через ЭЦП самостоятельно.
  5. Сохраните данные через «Подготовить заявку» в карточке интересного лота. При одинаковом товаре для всех позиций поставьте соответствующую галочку и нажмите «Подготовить черновик». Данные передаются прямо в расширение, JSON скачивать не нужно.
  6. На открывшейся вкладке Госзакупа откройте расширение и нажмите верхнюю кнопку «Создать / продолжить черновик». Передача данных сама не запускает заполнение заявки.
  7. Для статуса откройте «Мои заявки», найдите объявление, затем укажите в расширении БИН организации, полный номер объявления и лота. JSON подготовки для проверки не нужен. Нажмите «Проверить статус» и «Скачать отчёт проверки». При наличии сохранённой подготовки этого лота можно загрузить отчёт на её странице в нашем приложении. «Завершена» означает статус заявки, а не победу или проигрыш.

Для передачи без файла после проверки укажите адрес нашего приложения и нажмите «Передать в приложение». Заранее войдите на сайт, проверьте аккаунт и подтвердите сохранение в открывшейся вкладке. Лот должен находиться в вашем рабочем пространстве. Успех передачи подтверждается на сайте; товарные данные для этого не требуются.

Название компании, адрес, ИИК, банк, БИК и контактный телефон заполняются в разделе «Ваша организация» и подставляются в новую подготовку заявки.

Тип налогоплательщика выберите в реквизитах организации. Расширение подставит его при единственном точном совпадении с вариантом на Госзакупе.

Тестовая версия: разметку кабинета нужно проверить при первом использовании. Расширение останавливается перед обеспечением, ценой, подписанием и отправкой. При обрыве создания проверьте существующий черновик на портале: повторное создание блокируется. Постоянная фоновая синхронизация пока не подключена.

ЭЦП, пароль и сессия кабинета остаются на вашем компьютере. Файл подготовки содержит реквизиты — храните его приватно.

При обновлении распакуйте новый архив в ту же папку и нажмите «Обновить» на карточке расширения в Chrome. Папку расширения после установки не удаляйте.

Для прямой передачи нужна версия 0.7.0 или новее. После обновления расширения перезагрузите страницу подготовки. При переходе на другой адрес нашего приложения скачайте архив с этого адреса. Передача файлом остаётся в дополнительном разделе подготовки.
